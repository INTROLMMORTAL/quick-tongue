# quick-tongue

Бесплатное приложение для изучения английского с нуля. Работает как обычный сайт, без сервера и регистрации.

## Что есть в версии 1

- 5 юнитов (A0 → начало A2): приветствия, глагол to be, предметы и артикли, еда и have/like/want, Present Simple
- Каждый юнит: слова → диалог → грамматика → практика (около 24 заданий)
- Задания: выбор перевода, аудирование, сборка предложения, вставка пропущенного слова, диктант, проговаривание вслух
- Озвучка и распознавание речи прямо в браузере (лучше всего работает в Chrome и Edge)
- Интервальные повторения слов (система Лейтнера), словарь, серия дней, очки опыта
- Прогресс хранится в браузере (localStorage)

## Структура

```
index.html
css/style.css
js/data.js   ← содержание уроков (сюда добавляются новые юниты)
js/app.js    ← логика приложения
```

## Запуск

Открой `index.html` в браузере. Для публикации: Settings → Pages → Deploy from a branch → `main` / `/ (root)`.

## Как добавить юнит

Скопируй любой объект в массиве `UNITS` в `js/data.js` и поменяй слова, диалог, грамматику и предложения. Остальное приложение подстроится само.

## План

- Юниты 6–10 и дальше по CEFR
- Заменить голоса браузера записями диктора
- ИИ-собеседник (потребуется свой небольшой сервер)
